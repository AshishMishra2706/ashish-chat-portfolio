# Ashish Kumar Mishra - Chat Portfolio

This package is ready for GitHub Pages.

## Upload to GitHub

1. Open your repository.
2. Upload every file in this folder directly to the repository's main page.
3. Do not upload the ZIP file itself.
4. Enable GitHub Pages using the `main` branch and the `/(root)` folder.

All assets are deliberately kept in this one folder, so the resume, background, and icons work after upload.
